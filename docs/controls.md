# Controls

## Keyboard and mouse

| Input | Action |
|---|---|
| W / A / S / D | Move |
| Mouse | Look |
| Space | Jump or swim upward |
| Shift | Sprint |
| C / Ctrl | Crouch or fly downward |
| Double Space / G | Toggle Creative flight |
| Left mouse button | Mine or attack |
| Right mouse button / F | Place, use or interact |
| E | Inventory / collection |
| 1–9 / wheel | Select hotbar slot |
| Q | Drop selected item |
| Esc | Pause or close current panel |
| F3 | Performance information |

Right-click nearby residents, containers, stations and doors to interact. Hold crouch to place beside an interactive object. World modes are Creative, Survival, Adventure, Spectator and Hardcore.

## Touch and controller

Touch gameplay has a movement joystick, swipe-to-look, jump, mine, use, sprint, crouch, items and pause. Touch controls may be Auto, Always on or Off. Optional fullscreen and landscape orientation are controlled by the browser and may not be available. A connected standard Gamepad API controller can move, look, jump, sprint, use and switch slots; unsupported mappings are ignored. Menu controls remain available through native browser input.

## Worlds and backups

Choose **Create your world** or select a saved world on the home screen. Pause to save, export, change settings, open the Travel journal or return home. Saves are local to the current browser profile. Export backups regularly.
