# Architectural richness

The generator builds dense, connected Chinatown parcels while preserving street access, lot entrances, courtyard circulation and protected landmarks. Different buildings reuse deterministic designs and source data rather than placing random cosmetic shells over existing geometry.

Existing districts, roads, waterfront grades, Panda Plaza and regional reservations retain their authored footprints. Roofs, elevations, facades and courtyard compositions are varied within the same dense building program. Generator versions used by older saves remain supported without migration.

See [world planning](world-plan.md), [landmarks](landmarks.md) and [regional destinations](regional-destinations.md).
