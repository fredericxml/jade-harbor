# Gameplay controls — detailed reference

The canonical mappings and platform instructions live in [Controls](controls.md). Keyboard/mouse, touchscreen and controller adapters feed one gameplay action model; the same world and save rules apply to every input method.

Typical actions include move, look, jump, sprint, interact, break/place blocks, use selected item, open inventory and pause. Creative supports flight. Player motion respects world collision and selected game mode; touch controls do not bypass these checks.

To avoid stale duplicate key tables, use [Controls](controls.md) as the definitive guide.
