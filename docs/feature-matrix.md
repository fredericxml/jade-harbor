# Jade Harbor feature matrix

The features below describe the **Jade Harbor 2.1.0** source. Graphics quality changes presentation cost, not world rules, population or available gameplay actions.

| Area | Included |
|---|---|
| Game modes | Creative, Survival, Adventure, Spectator and Hardcore |
| World | One deterministic generator for all new and supported current-layout saves |
| City | Dense Chinatown districts, Panda Plaza, street markets, waterways, landmark precincts and regional destinations |
| Residents | Persistent resident identities, schedules, professions, navigation, activities and visual variation |
| Travel Journal | 33 discoveries grouped into 18 destination hubs in supported worlds |
| Interaction | Mining, placement, inventory, crafting, combat, equipment, block interactions and automation |
| Inputs | Keyboard/mouse, touch controls and common game controllers |
| Presentation | Sky, day/night, rain, fog, water, particles, terrain LOD, near/distant coverage, and Low/Medium/High presets |
| Saves | Browser IndexedDB with world export/import and compatibility checks; no cloud synchronization |
| Browser | WebGL2, installable PWA, offline resources where supported, and responsive UI |
| Diagnostics | Frame pacing, mesh/streaming backlogs, worker behavior, renderer information and optional GPU measurements |

See [world planning](world-plan.md), [living city](city-life.md), [travel destinations](travel-journal.md), [controls](controls.md), and [limitations](known-limitations.md) for details.

Feature availability and behavior can be subject to game mode and save-format validation. Individual test results do not certify every hardware/browser combination.
